# Reading a Wyoming Bill Record

**Draft only. Not on the website.** Source checked September 21, 2026. A named human
editor still needs to review the wording and sources. No human review is claimed.

## The Version Matters

A bill's title is only a starting point. Wyoming uses different names for the
text as it moves through the Legislature:

- **Introduced:** the starting proposal.
- **Engrossed:** includes changes adopted in the first chamber.
- **Enrolled:** the version passed by both chambers, including adopted changes.

"Engrossed" does not mean "signed into law." These terms describe different
steps. [Wyoming's 2026 Citizen Guide, pages 15-16](https://www.wyoleg.gov/docs/CitizenGuidebook.pdf#page=16).

## The Vote Matters Too

A bill can have several votes. A vote on an amendment is about a proposed change
to the text. It is not the same event as a vote on the bill's passage. The
official history keeps the stages separate. [Wyoming's legislative process,
page 16](https://www.wyoleg.gov/docs/CitizenGuidebook.pdf#page=17).

## A Date Can Change the Answer

An effective date says when the law begins to operate. It is not necessarily
the day of the vote or the day the governor signs. The text can set a different
date. [Wyoming's legislative process, page 16](https://www.wyoleg.gov/docs/CitizenGuidebook.pdf#page=17).

## A Simple Record to Keep

When saving a bill for later, keep these details together:

1. State, session year, and bill number.
2. The version of the text you read.
3. The action or vote and its date.
4. The official source link.
5. What is still unknown.

On Keeping Law Simple, a missing explanation does not mean a missing bill. The
available official links, history, and recorded votes remain on the page. A
summary is a reading aid, not a replacement for the official text.
